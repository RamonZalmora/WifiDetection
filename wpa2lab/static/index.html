Know the boundary

A scan cannot reveal a WiFi password. Generated laboratory data uses real WPA2 PMK, PTK, and EAPOL MIC verification, but comes from a synthetic exchange and does not prove router access.

No capture, disconnection, or interaction with discovered networks.

STEP 01–03 / SETUP

Generate laboratory data

The setup password derives a WPA2 PMK. A synthetic EAPOL message 2 and its MIC are retained in session memory; the password and PMK are not stored.

8–63 printable ASCII characters. The original password is cleared from this form after generation.

ALTERNATIVE / IMPORT

Authorized laboratory proof

Only validated wpa2lab-eapol-v1 JSON is supported: WPA2-CCMP EAPOL message 2 with descriptor version 2, MAC addresses, nonces, and MIC. Export generated data here, or prepare JSON from your authorized lab exchange as documented in README. Raw PCAP, PMKID, and hashcat files are unsupported. Unknown router passwords cannot be recovered from a scan.

General router guidance

Prefer WPA3-Personal or WPA2 with AES/CCMP. Update firmware through the vendor, check WPS in router settings, and choose a unique random passphrase. These recommendations are guidance, not findings about an unexamined router.
